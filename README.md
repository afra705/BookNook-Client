# 📚 BookNook – A Small Online Library

**🔗 Live Site:** https://booknook-psi.vercel.app/

## ✨ Features

- 📖 Browse all available books with detailed information.
- 🏷️ Filter books by different categories.
- 🔐 User registration and login with Google authentication.
- ➕ Add new books to the library.
- 📚 View and manage your own added books.
- 📥 Borrow available books from the library.
- 📋 View borrowed books in My Borrows.
- 👤 Update user profile information.
- 📱 Responsive design for desktop, tablet, and mobile devices.
